# R30 work and verification

## Approved behavior

- SA3/CA ONLY: BLOCK, WHIFF, or UNKNOWN uses the selected whiff-sound or
  main-music fade mode. The sound path stops the main track before playing the
  whiff file.
- ALL SUPERS: SA1/SA2 always play for four seconds and then fade; whiff sound
  does not apply to them. SA3/CA BLOCK or definite non-hit uses the selected
  action, while UNKNOWN keeps the main music playing.
- HIT keeps the main music playing. A later successful P1/P2 playback owns the
  single audible slot; delayed outcomes from superseded events cannot stop it.

## Diagnosis and implementation

- R29 P1 missed the recorded 3-to-1 spend because the 20 Hz path obtained only
  five to eight raw stable-baseline samples before the glyph disappeared. R30
  permits a stable three-gauge baseline to survive short glyph abstentions only
  after three consecutive trusted full-gauge colour samples. Conflicting raw
  glyphs do not count as baseline evidence.
- Production outcome observation now uses independently rectified health,
  drive, and timer HUD features instead of scene brightness. Normal matches use
  stable timer resumption. Training mode has no timer, so a result window may be
  established only after at least two unavailable HUD samples followed by at
  least three readable samples. Uninterrupted unchanged HUD remains UNKNOWN.
- A training result that proves no health or drive change but cannot distinguish
  perfect parry from a whiff is recorded as NON_HIT and displayed as
  `格挡/未命中`; it follows the same audio branch as BLOCK and WHIFF.
- The old per-side `fade_non_three` config key remains loadable for compatibility
  but no longer controls behavior. The panel states `全气：SA1/SA2 固定淡出`.
