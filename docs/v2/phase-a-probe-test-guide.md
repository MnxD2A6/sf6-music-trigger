# V2 第一阶段：REFramework 探针实测指南

目的：验证 REFramework 能否稳定读到双方角色、当前动作和 SA1/SA2/SA3/CA 事件，并收集命中、格挡、空挥时的数据。
这一阶段**不放音乐**，只记录日志。日志交回后，再开发正式的检测器和播放器桥接。

## 已安装内容

| 文件 | 位置 | 说明 |
|---|---|---|
| `dinput8.dll` | `<SF6 游戏目录>\` | REFramework nightly 01432（官方 GitHub 发布，2026-10-11） |
| `sf6_music_trigger_probe.lua` | `...\Street Fighter 6\reframework\autorun\` | 探针脚本，只读，不修改游戏、不发送输入 |

- **只在离线模式使用。** 打排位或联机前，请把 `dinput8.dll` 改名成 `dinput8.dll.off`，离线时再改回来。
- 游戏如果启动崩溃或异常：直接删除或改名 `dinput8.dll` 即可恢复原状。
- 游戏启动后会多出 REFramework 菜单，按 `F7` 打开或关闭。默认键是 `Insert`，这台电脑已在游戏目录的 `re2_fw_config.txt` 里改成了 F7；笔记本上可能要按 `Fn + F7`。

## 进入游戏后先确认

1. 进入**训练模式**，P1 选一个角色（建议先选隆 Ryu）。
2. 画面上应出现一个小窗口 **SF6 Music Trigger Probe**，内容类似：
   ```
   P1  chara=1  act=1  supers=9
   P2  chara=10 act=1  supers=6
   ```
   - `supers` 大于 0：说明该角色的超必杀招式表已经读到。
   - `act` 会随动作变化：说明动作读取正常。
3. 训练设置里把**超必杀槽设成无限 / 自动回满**，方便连续测试。

如果没看到这个窗口，按 `F7` 打开 REFramework 菜单，在 **Script Generated UI → SF6 Music Trigger Probe** 里勾选 `Show overlay`。

## 测试清单

**建议全程录屏**，用你以前的录屏方式就行。小窗口会出现在录像里，我可以逐秒对照"画面上放了什么招"和"探针记录了什么"，你就不用边打边记了。

角色按你以前测试视频里的阵容来：**杰米**（P1 主测）、**桑吉尔夫**（投技类超必杀）、**不知火舞**（2025 年 DLC，MMDK 数据里没有，用来验证新角色也能读到）。对手用桑吉尔夫或古烈都可以。

每一项做 **2 次**。放招后看小窗口有没有立即出现 `P1 SA3 start` 这类文字。

| # | 内容 | 设置方法 | 小窗口应显示 |
|---|---|---|---|
| A | 杰米 SA1、SA2、SA3 **命中** | 假人站着不防 | `P1 SAx start`，然后 `opp damage`，最后 `end ... opp=damage` |
| B | 杰米 SA1、SA2、SA3 **被防** | 假人设置 → 防御：全部防御 | `opp guard`，最后 `opp=guard` |
| C | 杰米 SA1、SA2、SA3 **空挥** | 离远一点放 | 最后 `opp=none` |
| D | 杰米 **CA** 命中 | 把 P1 血量设到 25% 以下，再放 SA3 的指令 | `P1 CA start` |
| E | **P2** 放超必杀 | 假人设置 → 录制：让 P2 录一个 SA3，再回放打 P1 | `P2 SA3 start` |
| F | **不知火舞** 重复 A 和 C | 回角色选择换成舞 | `P1 chara ...`、`super table: N actions`，之后能看到 `SAx start` |
| G | **桑吉尔夫** 投技超必杀命中和落空 | 换成桑吉尔夫，近身放一次、远处放一次 | 落空时最后应为 `opp=none` |
| H | 旧版容易**误触发**的动作 | 跳跃、空中攻击、普通必杀技、斗气相关动作、每局开场 | **不应**出现任何 `start` |
| I | （可选）**CPU 实战一局** | 对战模式打 CPU，像以前的 22 分钟实机视频那样 | 每次超必杀都只出现一次 `start` |
| J | （可选）**招式被打断** | 例如放 SA1 时被对手打中 | `end: interrupted_by_damage` |

A–H 是必测项，I 和 J 有时间再做。

## （可选）顺便试用 V2 播放器

正式检测脚本 `sf6_music_trigger.lua` 也已经装在 `reframework\autorun\` 里。它和探针可以同时运行，互不影响。想直接听效果的话：

1. 双击 V2 文件夹里的 `run_v2.bat`，打开 V2 面板。
2. **检测方式**选"REFramework 游戏内检测（推荐）"。**SF6 游戏目录**应该已经自动填好。
3. 和以前一样选择 P1/P2 的音乐和大招范围，然后点**开始**。
4. 状态栏显示"监听中（REFramework）"后，进训练场放超必杀，应该能立刻听到音乐。

如果音乐和探针小窗口的判断不一致，请记下来，这正是要找的问题。

## 测试完成后

1. 正常退出游戏。
2. 日志在 `<SF6 游戏目录>\reframework\data\SF6MusicTrigger\`：
   - `probe-日期-时间.jsonl`：事件日志
   - `schema-日期-时间.json`：游戏内部结构，用来找"哪边是玩家、哪边是 CPU"的字段
3. 把文件留在原位，告诉我测试做完了。录屏照常保存到你平时的 `屏幕录制\SF6` 文件夹，起个能认出来的名字，例如 `V2探针测试.mp4`。我可以直接读取日志和视频，不用复制。
4. 如果 REFramework 报错，游戏目录下的 `re2_framework_log.txt` 也一起留着。

日志里只有角色编号、动作编号和数值字段，没有截图、音频或个人信息。

## 我会用日志确认什么

运行 `python tools/analyze_probe_log.py <probe-xxx.jsonl>` 可以得到：

- 双方角色和超必杀招式表是否读到，以及 SA1、SA2、SA3、CA 的动作编号。
- 每次超必杀是否只触发一次（没有重复），以及结束原因。
- 对手的反应：damage（命中）、guard（格挡）或 none（空挥）。
- 哪个字段在放招时正好减少 10000、20000 或 30000，也就是超必杀槽字段。
- 哪个字段在命中时减少，也就是对手血量字段。
- 哪个字段能区分玩家和 CPU，用于自动判断"我是 P1 还是 P2"。
