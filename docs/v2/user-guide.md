# SF6 Music Trigger V2 使用说明

V2 在游戏里直接读取超必杀事件，不看画面，所以换 UI、换分辨率、全屏都不影响识别。音乐由外面的 V2 播放器播放；设置可以在播放器面板里改，也可以在游戏里打开 REFramework 菜单直接改。

> 只用于离线模式：训练模式、CPU 对战、本地对战。联机前请把游戏目录里的 `dinput8.dll` 改名（例如 `dinput8.dll.off`）。

## 第一次使用（解压即用）

1. 把发布的 ZIP 完整解压到任意文件夹。不用安装，也不写注册表。
2. 关闭游戏，双击 `SF6 Music Trigger.exe`（从源码运行时双击 `run_v2.bat`）。
3. **检测方式**选"REFramework 游戏内检测（推荐）"。**SF6 游戏目录**通常会自动填好。
4. 点 **一键安装/更新**，它会往游戏目录放进三个文件：
   - 附带的 REFramework（`dinput8.dll`）。如果你已经装了自己的版本，可以选择保留。
   - `sf6_music_trigger.lua`：检测超必杀。
   - `sf6_music_trigger_ui.lua`：游戏内的设置窗口。
5. 为 P1/P2 选好音乐（可以放进程序旁边的 `music` 文件夹），然后点 **开始监听**。
6. 建议勾选 **启动后自动开始监听并最小化**。以后打开播放器就会自动在后台工作，不用再切出游戏。

## 卸载

1. 关闭游戏，在面板里点 **从游戏中移除**：
   - V2 的两个脚本和日志文件夹会被删除。
   - 游戏里没有其他 REFramework Mod 时，会询问是否连 REFramework 一起删除。选"是"后，游戏目录恢复原样。
   - 有其他 Mod 时，会自动保留 REFramework。
2. 再删除程序文件夹，就没有任何残留了。游戏本身的文件从来不会被改动。

## 在游戏里改设置

按 REFramework 的菜单键打开菜单时（默认是 **Insert**；键盘没有 Insert 的话，可以在 REFramework Config → Menu Key 里改成 F7 之类的键），会同时出现 **SF6 音乐设置** 窗口，可以改：

- 开始/停止监听
- 应用音频模板
- 解除音量上限、重置音量
- P1/P2 各自的启用开关、主音乐、音量、大招范围、空大/被防时的处理（播放打空音效或淡出主音乐）、打空音效及其音量，以及试听

几点说明：

- 改动会立即生效并自动保存，正在监听时也不用重新开始。
- 可选的音乐来自已选音乐所在的文件夹，以及播放器配置目录下的 `music` 文件夹。要添加新歌，把文件放进这些文件夹即可，几秒后游戏内的列表就会更新。
- 再按一次菜单键关闭菜单，设置窗口会一起隐藏。不想让它随菜单出现，可以在 REFramework 菜单 → Script Generated UI → SF6 音乐设置 里关掉。
- 窗口显示"未连接 V2 播放器"，表示播放器没在运行。

## 音量

- 100% 是音乐文件本身的音量。
- 勾选 **解除音量上限** 后最高可以到 500%。超过 100% 的部分是把音频放大，响的段落会被平滑压住，所以调得很高时会有明显的压缩感。
- 开始监听时会预先算好放大后的音乐，所以放大不会让音乐出来得更慢。
- **重置音量** 会把 P1、P2 的主音乐和打空音效都恢复到 100%。

## 播放规则

| 情况 | 全部大招 | 仅 SA3/CA |
|---|---|---|
| SA1 / SA2 | 播放，满 4 秒后淡出 | 不播放 |
| SA3 / CA 命中 | 一直播放 | 一直播放 |
| SA3 / CA 被防或空大 | 立即播放打空音效，或在开始播放满 4 秒后淡出 | 同左 |
| SA3 / CA 结果不确定（例如被打断） | 继续播放 | 淡出 |
| 对方随后也放了超必杀 | 后放的一方接管音乐 | 同左 |

- **空大**：在超必杀的攻击判定帧结束后立即判定，大约在放招后 2 秒内。飞行道具类超必杀要等收招才判定。
- **被防**：对手一防住就立即判定。

## 文件位置

- 播放器配置：`%LOCALAPPDATA%\SF6MusicTrigger\config.json`
- 游戏内数据：`<游戏目录>\reframework\data\SF6MusicTrigger\`
  - `events.jsonl`：超必杀事件
  - `app_state.json`：给游戏内窗口显示的设置
  - `ui_commands.jsonl`：游戏内窗口发出的修改

以上文件都只在本机，不会上传。
